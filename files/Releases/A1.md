## Motivation: From Scalars to Relations

### The Standard Computational Picture

In contemporary machine learning and signal processing, the canonical workflow is:


$$\text{Signals} \xrightarrow{\text{Parametrize}} \text{Kernels } \{h_1, \ldots, h_N\} \xrightarrow{\text{Evaluate}} \text{Scalars } \{y_1, \ldots, y_N\} \xrightarrow{\text{Compare/Order}} \text{Relationships}$$


**Example:** To rank $N$ learned convolutional filters by their effectiveness on a signal, we:
1. Convolve the signal with each filter: $y_i = x * h_i$ (cost: $O(N \cdot K \cdot L)$ where $K$ = kernel size, $L$ = signal length)
2. Compare the scalars: $y_1$ vs $y_2$ vs ... (cost: $O(N^2)$ comparisons)
3. Output the ordering


But consider a different question: what if we only care about the relational structure, not the exact scalar values?

**Observation**: Many downstream applications (ranking, selection, control decisions,..) depend only on the ordering of scalars, not their precise magnitudes.

Reframe the problem geometrically, in this space:

+ Distance between two convolutions/inner-products represents their "difference in effect"

+ Order relations, the lattice structure?

+ Comparisons can be made by examining the compressed representation of this space (e.g., via dimensional reduction, sketching, bounds)?

## Formal Framework: Hung's method

### 2.1 Core Definition

The core of this method is fully compatible and can be directly adapted to allow inner products. Phép tích vô hướng giữa hai vector bản chất chính là một phép toán tensor cơ bản nhất (tensor contraction bậc 1).

**Definition 2.1 (Inner Product Space)**

Let $\mathcal{H}$ be a set of candidate vectors of a fixed high dimension $D$:  

$$\mathcal{H} = \{h \in \mathbb{R}^D \mid \Vert{}h\Vert{}_2 \leq 1\}$$

For a fixed query vector $x \in \mathbb{R}^D$, the inner product operator induces a scalar map:  

$$\Phi_x: \mathcal{H} \to \mathbb{R}$$

$$\Phi_x(h) = \langle x, h \rangle$$

The critical observation: The map $\Phi_x$ induces an ordering on $\mathcal{H}$:  

$$h_i \preceq_x h_j \iff \vert{}\Phi_x(h_i)\vert{} \leq \vert{}\Phi_x(h_j)\vert{}$$

for scalar magnitude comparisons (or strictly $\Phi_x(h_i) \leq \Phi_x(h_j)$ if signed ordering is required).  

**Standard approach**: To compute $h_i \preceq_x h_j$, evaluate both $\Phi_x(h_i)$ and $\Phi_x(h_j)$ completely.  

Cost: $O(D)$ per pair.  


**Definition 2.2 (Relational Inner-Product Algebra)**

A Relational Inner-Product Algebra (RIA) over $\mathcal{H}$ is a tuple $(\mathcal{A}, \sigma, \preceq, d)$ where:

$\mathcal{A}$ is a representation space (typically $\mathbb{R}^m$ where $m \ll D$)  

$\sigma: \mathcal{H} \to \mathcal{A}$ is an encoding functor that maps each vector to a compressed representation

$\sigma$ must be efficiently computable: $\text{Cost}(\sigma(h)) = o(D)$

Examples: Locality-Sensitive Hashing (LSH), random projections, tensor sketches

$\preceq$ is a partial order on $\mathcal{A}$ such that: 

$$\sigma(h_i) \preceq \sigma(h_j) \implies h_i \preceq_x h_j \quad \text{(order-preserving property)}$$

Not all elements are comparable (lattice structure, not total order)

Comparisons in $\mathcal{A}$ are efficient: $\text{Cost}(\sigma(h_i) \preceq \sigma(h_j)) = o(D)$

$d: \mathcal{A} \times \mathcal{A} \to \mathbb{R}_{\geq 0}$ is a distance metric such that:

$$\vert{}d(\sigma(h_i), \sigma(h_j)) - d_{\text{true}}(h_i, h_j)\vert{} \leq \epsilon \quad \text{(approximation guarantee)}$$

where $d_{\text{true}}$ is the ground-truth geometric distance between vectors. 

### 2.2 Order-Preserving Property and Lazy Evaluation Bounds


The key innovation is lazy evaluation with interval bounds. Rather than computing $\Phi_x(h_i)$ fully, we maintain bounds on the output scalar:


**Definition 2.3 (Lazy Interval Bounds)**

For each vector $h_i \in \mathcal{H}$, define:

$$L_i = \inf \{\vert{}\Phi_x(h_i)\vert{} : h_i \text{ satisfies constraints from } \sigma(h_i)\}$$

$$U_i = \sup \{\vert{}\Phi_x(h_i)\vert{} : h_i \text{ satisfies constraints from } \sigma(h_i)\}$$


These bounds are computed from the representation $\sigma(h_i)$ without fully evaluating the inner product.

**Theorem 2.1 (Early Termination for Ordering)**

If $U_i < L_j$, then $h_i \prec h_j$ (strict ordering) without computing $\Phi_x(h_i)$ or $\Phi_x(h_j)$ in full. 

**Proof.**

By definition of bounds: $\vert{}\Phi_x(h_i)\vert{} \leq U_i < L_j \leq \vert{}\Phi_x(h_j)\vert{}$, so the ordering holds with certainty. ◻

Consequence: Comparisons early-terminate when bounds are tight enough. Only ambiguous cases require full evaluation.


### 2.3 Lattice Structure Preservation

**Theorem 2.2 (RIA Lattice Structure)**

If $\sigma$ satisfies the order-preserving property, then $(\sigma(\mathcal{H}), \preceq)$ forms a lattice with:  

Meet (greatest lower bound): $\sigma(h_i) \sqcap \sigma(h_j) = \sigma(h_{\min})$ where $h_{\min}$ is the vector "between" $h_i$ and $h_j$ in the original space

Join (least upper bound): $\sigma(h_i) \sqcup \sigma(h_j) = \sigma(h_{\max})$

This lattice structure is inherited from the natural lattice structure of $\mathcal{H}$ under the inner product metric.  

**Consequence:**

Comparisons in the RIA are consistent with the underlying relational structure of vectors. We're not imposing an artificial order; we're making the natural order explicit.  

### 2.4 Bổ sung

**Theorem: Relational Completeness**

For any RIA $(\mathcal{A}, \sigma, \preceq, d)$ with order-preserving property and lazy bounds as defined in Definition 2.3:

1. All definitively comparable pairs $(h_i, h_j)$ (where $U_i < L_j$ or vice versa) are determined without full evaluation

2. Ambiguous pairs (where bounds overlap) form a set of measure $O(\epsilon)$ in the space of all pairs

3. The transitive reduction of the order relation $\preceq$ on $\mathcal{A}$ is equivalent to the transitive reduction of the true order on $\mathcal{H}$ (up to ambiguous pairs)

Consequence: The RIA preserves all certain relational structure without full computation.

**Theorem (Lattice Homomorphism Property).**

Let $\mathcal{L}_{\mathcal{H}}$ be the lattice of vectors under the inner product order, and $\mathcal{L}_{\mathcal{A}}$ be the lattice of representations under $\preceq$.  

If $\sigma$ is order-preserving (Definition 2.2, property 3), then:

$$\sigma: \mathcal{L}_{\mathcal{H}} \to \mathcal{L}_{\mathcal{A}}$$

is a lattice homomorphism, meaning:

$$\sigma(h_i \sqcap h_j) \preceq \sigma(h_i) \sqcap \sigma(h_j)$$

$$\sigma(h_i) \sqcup \sigma(h_j) \preceq \sigma(h_i \sqcup h_j)$$

Consequence: The RIA respects the algebraic structure of the inner product space. Queries on the RIA yield results consistent with the true order.

# Appendix A: Proofs of Main Theorems

## A.1 Proof of Theorem 2.1 (Early Termination)

Claim: If $U_i < L_j$, then $h_i \prec h_j$ without full evaluation.

**Proof:**

By definition, $L_j$ is the lower bound on $\vert{}\Phi_x(h_j)\vert{}$, so:

$$\vert{}\Phi_x(h_j)\vert{} \geq L_j$$

Similarly, $U_i$ is the upper bound on $\vert{}\Phi_x(h_i)\vert{}$:  

$$\vert{}\Phi_x(h_i)\vert{} \leq U_i$$

Given $U_i < L_j$: 

$$\vert{}\Phi_x(h_i)\vert{} \leq U_i < L_j \leq \vert{}\Phi_x(h_j)\vert{}$$

Therefore, $\vert{}\Phi_x(h_i)\vert{} < \vert{}\Phi_x(h_j)\vert{}$, establishing $h_i \prec h_j$. ◻

## A.2 Proof of Theorem (Relational Completeness)

Claim: Definitively comparable pairs are determined without full evaluation.

**Proof sketch:**

The set of ambiguous pairs is those where bounds overlap: $[L_i, U_i] \cap [L_j, U_j] \neq \emptyset$.  

By construction of lazy bounds from the representation $\sigma(h)$, if the representation is order-preserving, the bounds converge to the true values as more information from $\sigma$ is extracted.  

For bounded representation spaces (e.g., lower-dimensional sketches mapped to $\mathbb{R}^m$), the error in bounds is $O(\epsilon)$ where $\epsilon$ depends on the projection dimensionality or hash bit length.  

Thus, the measure of ambiguous pairs scales as $O(\epsilon)$ in the space of all pairs.  ◻


## A.3 Proof of Theorem (Information-Theoretic Lower Bound)

Claim: If ordering can be arbitrary, cost is $\Omega(N \log N)$.  

**Proof:**

There are $N!$ possible orderings of $N$ vectors. To distinguish between them, any algorithm must encode at least $\log_2(N!) = \Theta(N \log N)$ bits.  

Under the standard RAM model (word size $O(\log n)$), this translates to $\Omega(N \log N)$ comparisons or equivalent bit operations.

Thus, the minimum cost is $\Omega(N \log N)$.  ◻
